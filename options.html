PR Comment → Agent

Settings for the T3 Code, Cursor and copy buttons on pull request review comments.

Prompt

Leave empty to use the default.

T3 Code

The thread opens in the T3 Code project that matches the GitHub repository, as a draft. Nothing runs until you press Send.

Cursor

Cursor sends the prompt to the open window whose folder name matches. By default that is the repository name; add a line here when your local folder is named differently.
